# tiktok_download.py

Скачивает видео из TikTok по ссылке — без вотермарки, без зависимостей (только
стандартная библиотека Python 3.8+).

```bash
python3 scripts/tiktok_download.py https://www.tiktok.com/@user/video/123456
python3 scripts/tiktok_download.py -o downloads --json --cover <url1> <url2>
python3 scripts/tiktok_download.py --list urls.txt          # пачкой из файла
python3 scripts/tiktok_download.py --yt-dlp <url>           # запасной путь
```

Файлы кладутся в `downloads/` (меняется через `-o`) с именем
`{автор}_{id}.mp4`. Путь к скачанному файлу печатается в stdout — удобно
подставлять в пайплайн.

## Флаги

| Флаг | Что делает |
| --- | --- |
| `--list FILE` | ссылки из файла, по одной на строку (`#` — комментарий) |
| `--out DIR`, `-o` | папка для файлов (по умолчанию `downloads`) |
| `--json` | рядом с видео сохранить метаданные: описание, автор, статистика, музыка |
| `--cover` | сохранить обложку `.jpg` |
| `--music` | сохранить аудиодорожку `.mp3` |
| `--title` | добавить описание поста в имя файла |
| `--watermark` | версия с вотермаркой вместо чистой |
| `--overwrite` | перезаписывать уже скачанное (по умолчанию пропускает) |
| `--yt-dlp` | качать через yt-dlp вместо прямого разбора страницы |
| `--delay N` | пауза между ссылками, сек (по умолчанию 1) |
| `--quiet`, `-q` | без прогресса |

Фото-посты (слайдшоу) скачиваются как набор `_01.jpg`, `_02.jpg`, …

## Как это работает

Скрипт открывает страницу поста, достаёт из inline-скрипта JSON-состояние
(`__UNIVERSAL_DATA_FOR_REHYDRATION__`, с фолбэком на старый `SIGI_STATE`), берёт
оттуда прямую ссылку на mp4 с максимальным битрейтом и качает файл с теми же
cookies и `Referer` — без них CDN отдаёт 403.

## Если сломалось

TikTok периодически меняет разметку и включает антибот-проверки. Типичные
ошибки:

- **«на странице нет данных поста»** — отдали капчу или страницу входа.
  Попробуйте `--yt-dlp` (`pip install yt-dlp`), там разбор поддерживают активнее.
- **«пост приватный»** — доступ закрыт, скачать нельзя.
- **«ни одна прямая ссылка не отдала файл»** — ссылка на CDN протухла;
  перезапустите, страница отдаст свежую.

Скачивайте только то, на что у вас есть права: свои ролики или чужие с
разрешения автора.
