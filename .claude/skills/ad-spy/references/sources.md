# Источники: где лежит активная реклама конкурентов

## Правило, которое экономит время

Не собирай URL руками по параметрам. Открой библиотеку в браузере, выстави
фильтры в её же интерфейсе, скопируй адресную строку и передай её как query:

```bash
python3 scripts/spy_sources.py "https://www.facebook.com/ads/library/?active_status=active&..." -o ~/spy/x
```

URL, начинающийся с `http`, идёт в браузер как есть. Параметры ниже — чтобы
понимать, что в этом URL написано, и уметь его подправить.

---

## Meta Ad Library — главный источник

`https://www.facebook.com/ads/library/` — Facebook + Instagram, все страны, без
логина. Единственная библиотека, которая отдаёт **дату запуска** и **число
вариантов** в связке, то есть позволяет отличить победителя от свежего теста.

| Параметр | Значения | Зачем |
|---|---|---|
| `active_status` | `active` / `inactive` / `all` | нас интересует `active` |
| `country` | ISO-код (`US`, `GB`, `DE`) или `ALL` | выдача по странам сильно разная |
| `q` | ключевое слово | поиск по тексту объявлений и названиям страниц |
| `search_type` | `keyword_unordered` / `keyword_exact_phrase` / `page` | точность поиска |
| `view_all_page_id` | цифровой ID страницы | все объявления конкретного рекламодателя |
| `media_type` | `video` / `image` / `all` | нам обычно `video` |
| `ad_type` | `all` и спец-категории | оставляй `all` |
| `publisher_platforms[0]` | `facebook` / `instagram` | развести плейсменты |
| `start_date[min]` | `YYYY-MM-DD` | «что запустили после...» |

**Поиск по бренду vs по странице.** Поиск по слову притаскивает и чужие
объявления, где бренд упомянут. Точнее так: найди бренд поиском, открой его
карточку, забери цифровой `page_id` из URL и гоняй сбор по нему.

**Что отдаёт узел объявления:** `adArchiveID`, `startDate`, `endDate`,
`isActive`, `collationCount` (варианты), `pageName`/`pageID`,
`publisherPlatform`, и внутри `snapshot` — тексты (`title`, `body`, `caption`),
`cta_text`/`cta_type`, `link_url` (лендинг с UTM-метками — по ним видно
структуру кампаний), `videos[].video_hd_url`, превью. Для ЕС дополнительно
приезжают охваты.

**Чего там нет:** расхода, CTR, CPM, аудиторий. Всё это — только косвенно через
срок жизни и число вариантов.

**Официальный Graph API** (`/ads_archive`) закрывает только политическую и
социальную рекламу, для коммерческой не годится. Полные данные ЕС лежат в Meta
Content Library и выдаются исследователям по заявке. Проверяй актуальность
правил, они меняются.

## TikTok Creative Center — топ по нише

`https://ads.tiktok.com/business/creativecenter/inspiration/topads/pc/en`

Витрина лучших рекламных роликов, отобранных самим TikTok. Без логина.
Полезна, когда нужен не конкретный бренд, а «что вообще работает в нише».

Фильтры в URL: `period` (7 / 30 / 180 дней), `region`, `industry`, `objective`,
сортировки по CTR и вовлечению. Собери в интерфейсе — скопируй URL.

Отдаёт `ctr`, лайки/комментарии/репосты, индустрию, цель кампании, прямую
ссылку на mp4 и длительность. **Дат показа не отдаёт** — статусов по сроку
жизни здесь не будет, сравнивать с Meta напрямую нельзя.

---

## TikTok Ad Library (ЕС) — даты и охваты

`https://library.tiktok.com/ads` — библиотека коммерческого контента по
требованиям ЕС. Есть поиск по рекламодателю, даты первого и последнего показа,
охваты. Работает только по европейским странам. В скилле это `-s tiktok-library`.

---

## Google / YouTube — Ads Transparency Center

`https://adstransparency.google.com` — реклама конкретного рекламодателя,
включая ролики на YouTube, с датами показа и форматом. Внутренний API отдаёт
упакованный protobuf, автоматический перехват здесь не окупается.

Практический маршрут: найди рекламодателя в интерфейсе, собери ссылки на
ролики руками, скачай через **yt-grab**, а разбор запусти обычной командой:

```bash
python3 scripts/spy_dissect.py -o ~/spy/brand    # видео уже лежит в media/, запись в ads.json добавь вручную
```

## Остальные библиотеки

Есть у LinkedIn, Pinterest, Snapchat, Reddit, X. Все — по той же логике
прозрачности, все отдают меньше, чем Meta. Если ниша живёт там, добавь источник
в `SOURCES` в `spy_sources.py`: нужен построитель URL, кусок адреса XHR и
функция нормализации. Каркас перехвата общий, писать заново ничего не нужно.

---

## Что не является библиотекой рекламы

Профиль конкурента в TikTok/Instagram и его ролики на YouTube — это органика.
Она полезна (видно, что зашло без бюджета), но срока открутки там нет, и путь
к ней другой: **tiktok-grab** и **yt-grab**. Не путай одно с другим в отчёте —
у органики и рекламы разные сигналы успеха.
